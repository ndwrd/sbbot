## Привязка своей группы outbound к конкретной ноде (`~geo:CODE~`)

Если в своём кастомном шаблоне подписки (sing-box/mihomo) нужна отдельная
группа, которая ходит только через определённый сервер (например, отдельный
`urltest` для конкретного сайта через ноду в нужной стране) — используйте
плейсхолдер `~geo:CODE~`.

**1. Узнать код ноды.** Bot → Nodes → нужная нода — код виден в теге её
outbound'ов (например `🇷🇺RU|Vless`) сразу после флага: `RU`. Если у
нескольких серверов совпадает страна, у второго и далее будет цифра: `RU2`,
`DE3` и т.д.

**2. Вписать `~geo:CODE~`** как элемент массива `outbounds` (sing-box) /
`proxies` (mihomo) в своей группе шаблона. На сборке подписки он
разворачивается в реальные теги всех включённых у этой ноды протоколов
(Vless/Naive/Hy2/Anytls).

Sing-box, пример — группа "Youtube" только через ноду RU:
```json
{
    "type": "urltest",
    "tag": "Youtube",
    "outbounds": ["~geo:RU~"],
    "url": "https://www.gstatic.com/generate_204",
    "interval": "5m"
}
```

Mihomo/Clash, тот же смысл:
```json
{
    "name": "Youtube",
    "type": "url-test",
    "proxies": ["~geo:RU~"],
    "url": "https://www.gstatic.com/generate_204",
    "interval": 300
}
```

Можно смешивать с обычными тегами в том же массиве:
`"outbounds": ["~geo:RU~", "~geo:DE~"]` или `["~geo:RU~", "🇩🇪DE|Vless"]`.

Если нода в момент генерации подписки недоступна/выключена/не
синхронизирована — `~geo:CODE~` просто пропадает из списка (группа
останется с меньшим числом участников), конфиг не ломается.
